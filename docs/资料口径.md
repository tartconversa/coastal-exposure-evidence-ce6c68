# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

腐蚀事件为区间结局：巡检 clear 到首次 corrosion 之间只知发生区间；没有 corrosion 不代表全寿命通过。stop_reason 的 safety、machine、planned 分别是安全停止、舱机故障和计划结束；不得合并成同类阴性。protocol 的不同循环仅作为真实暴露描述，没有既定加速年限换算。现场更换密封设计后开始新的经历，原段以更换终止。客户风险上限针对给定时长内首次腐蚀；支持状态由应用结合资料决定，输入不含通过答案。

## designs
柜体设计与制造批。

记录键：['batch_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| design_id | string | 设计 |
| batch_id | string | 制造批 |
| seal | string | 密封代际 |

## specimens
独立试样及结束原因；同批试样相关。

记录键：['specimen_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| specimen_id | string | 试样 |
| design_id | string | 设计 |
| batch_id | string | 批次 |
| protocol | string | 协议 |
| stop_reason | string | 停止原因 |
| end_hour | integer | 结束暴露小时 |
| physical_state | string | 现存或已破坏 |

## exposures
每段实际经历，不给等效年限。

记录键：['exposure_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| exposure_id | string | 段号 |
| specimen_id | string | 试样 |
| start_hour | integer | 起点小时 |
| end_hour | integer | 终点小时 |
| salt_g_l | number | 盐浓度克每升 |
| humidity_pct | number | 相对湿度百分比 |
| stage | string | 阶段 |

## inspections
巡检状态的完整记录；首个腐蚀之后仍可重复观察。

记录键：['inspection_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| inspection_id | string | 检查 |
| specimen_id | string | 试样 |
| hour | integer | 暴露时点小时 |
| finding | string | clear或corrosion |
| available_at | datetime | 可知时点 |

## field_spells
现场设计经历；结局记录不包含未观察的准确失效时刻。

记录键：['spell_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| spell_id | string | 经历 |
| unit_id | string | 设备 |
| design_id | string | 设计 |
| environment | string | 环境 |
| start | date | 起日 |
| end | date | 止日 |
| last_clear_day | integer | 相对资料原点末次清晰日数 |
| last_seen_day | integer | 末次可见日数 |
| end_reason | string | seal_change或censored或corrosion |
| available_at | datetime | 可知时点 |

## requests
待比较客户用途，每行一个环境权重。

记录键：['request_id', 'environment']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| request_id | string | 用途 |
| environment | string | 环境 |
| share | number | 需求构成比例 |
| duration_days | integer | 承诺天数 |
| risk_limit | number | 首次腐蚀风险上限 |
| cabinets | integer | 需求柜数 |
| decision_by | date | 答复期限 |

## chambers
共享舱位真实可用时段。

记录键：['slot_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| slot_id | string | 时段 |
| chamber_id | string | 舱 |
| protocol | string | 支持协议 |
| start | date | 开始 |
| end | date | 结束 |
| capacity | integer | 试样数 |
| cost_each | number | 每样费用 |
| reserved | integer | 其他项目已占 |

## test_actions
可选实验的实物与费用契约。

记录键：['action_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| action_id | string | 动作 |
| protocol | string | 协议 |
| destructive | boolean | 是否破坏 |
| hours | integer | 暴露小时 |
| cost | number | 费用 |

## planning_budget
本轮可用资金，不预先划定探索与补证比例。

记录键：['plan_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| plan_id | string | 计划 |
| budget | number | 本轮预算 |
| decision_date | date | 安排日 |
